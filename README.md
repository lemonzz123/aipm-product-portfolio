# 🧠 LLM B端应用实践 | RAG & Agent Demo
> AI产品落地实践项目，面向企业知识库、智能问答、工作流Agent场景

## ✨ 项目简介
本项目是一套大模型应用原型落地Demo，聚焦B端企业服务场景，围绕RAG知识库检索、Agent工作流编排、对话交互链路做产品侧全流程验证。
侧重**产品视角**：需求拆解、流程设计、Prompt策略、评测体系、边界约束、原型与PRD配套，不是纯算法调优项目，适合AI产品方案验证、面试作品集展示。

### 核心能力
- ✅ 企业私有知识库RAG：文档上传、切片、向量化、检索召回、引用溯源
- ✅ Agent工作流编排：工具调用、条件分支、多步骤任务拆解
- ✅ 对话交互模块：会话管理、历史记录、人工兜底、输出校验
- ✅ 评测模块：回答准确率、召回率、幻觉识别、自助解决率统计
- ✅ 配套交付：低保Figma原型、PRD、字段说明、验收标准

## 📌 产品设计要点
1. 区分模型能力边界，设置降级、兜底机制
2. 检索可配置：切片大小、重排开关、引用来源展示
3. 面向业务人员：低代码Agent节点可视化配置
4. 数据埋点：用户提问、失败case、自助解决率统计
5. 合规：敏感词过滤、溯源、回答可审计
