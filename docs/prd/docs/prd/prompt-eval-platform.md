# 项目3：Prompt评测&模型效果平台 PRD
## 1. 项目概述
### 1.1 背景
大模型版本迭代、Prompt修改后，很难量化效果好坏；人工评测效率低、标准不统一，无法稳定对比不同Prompt、不同模型版本的输出质量。
### 1.2 项目目标
- 业务目标：建立标准化评测集，自动+人工结合打分，量化Prompt/模型版本效果，降低人工评测成本
- 用户：AI产品、算法、测试
- 上线范围：内部AI项目组使用

## 2. 用户角色
1. 评测管理员：创建评测集、录入Case、配置打分规则、新建评测任务
2. 评测员：人工打分、填写评语
3. 产品/算法：查看评测报告、对比版本指标、导出结果

## 3. 功能需求
### 3.1 评测用例管理
- 用例分组：按业务场景分类（知识库问答、摘要、提取）
- 单条Case：输入Prompt、预期标准答案、评分维度（准确性、简洁、合规）
- 批量导入：Excel批量上传测试用例
- 用例启用/禁用

### 3.2 评测任务管理
- 新建任务：选择评测集、选择模型、填写待测试Prompt
- 自动批量跑测：批量调用模型生成回答
- 评测模式：自动打分（规则/模型打分）+人工复核打分
- 任务状态：待执行、运行中、待人工评审、已完成

### 3.3 对比报告
- 多版本对比：同一个测试集，横向对比Prompt A / Prompt B，或者模型v1/v2
- 指标：平均分、准确率、合规率、失败率
- 可视化图表：分数分布柱状图
- 报告导出：Excel结果包

### 3.4 打分配置
- 自定义评分维度，每个维度设置权重
- 打分选项：1-5分，或者合格/不合格二元打分
- 支持备注：标记幻觉、拒绝回答、内容越界

## 4. 非功能需求
- 并发：批量跑测限流，避免高频调用模型API
- 数据：评测数据保存，历史任务永久留存
- 权限：评测集可以设置项目内可见
- 兼容：PC浏览器

## 5. 业务规则
1. 自动打分仅作为参考，关键场景必须人工复核
2. 同一个Case，不同版本模型输出会放在一行并排对比，方便评审
3. 标记幻觉的样本，自动汇总到问题样本库

## 6. 验收标准
1. 支持批量导入测试用例，批量调用模型生成回答
2. 支持人工打分，生成对比报告
3. 可以两个Prompt/模型版本横向对比指标
4. 结果支持导出Excel
